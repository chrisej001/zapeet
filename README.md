# Zapeet — Marketing Landing Page

Insured checkout. Automated delivery. Marketing site for Zapeet, built for Lagos vendors.

## Stack

Plain static HTML/CSS, no build step. Deploys directly to Vercel.

## Local preview

Open `index.html` in a browser, or serve it locally:

```
npx serve .
```

## Deploy

Push to GitHub, then import the repo in Vercel (Framework Preset: "Other" / static). No environment variables or build command needed.

## Brand

Colors, type, and voice follow `zapeet_brand_guidelines.pdf` (v1.0, Aug 2026):

- ink indigo `#1B1F3B` — primary
- marigold `#F2A93B` — accent / insured flow
- terracotta `#D85A30` — delivery flow
- paper `#F7F4EE` — background
- ink 60% `#5C6079` — body text
- Typeface: Inter
